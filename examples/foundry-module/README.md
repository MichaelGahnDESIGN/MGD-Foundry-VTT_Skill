# Foundry-Modul-Beispiel

Ein eigenes Modul sollte eine eindeutige Modul-ID, `module.json`, getrennte JavaScript-/CSS-Dateien und eine kurze README besitzen. Für Suchfenster:

- Suche nach Journalen und Items getrennt anbieten;
- bei Items nach Typ, Seltenheit, magisch/nicht-magisch und Ordner filtern;
- keine privaten Dokumente automatisch veröffentlichen;
- nach jeder Foundry-Hauptversion Syntax und sichtbares Verhalten prüfen.

Dieses Beispiel enthält absichtlich keine privaten Kampagnendaten.
